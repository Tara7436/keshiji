# 课时记 · 学生课时台账

给独立老师用的课时管理工具：每天几秒钟记完上课 / 请假 / 购课，随时看清每个学生的剩余课时、该续费的人，以及当月课消收入。

## 功能

- **学生台账**：学生列表，剩余课时按状态显示（绿正常 / 黄剩 2 节该续费 / 红剩 1 节 / 灰用完），支持搜索、排序。
- **续费提醒带**：首页顶部醒目列出「已用完 / 剩 1 节 / 该续费」的学生。
- **课时操作**：消课（默认 1 节，可 2 节）、请假（不扣课时、顺延）、购课（+10 / +20 / 自定义），操作后可撤销。
- **课时流水**：每个学生一笔可追溯的明细（时间、类型、节数、操作后剩余）。
- **收入统计**：按月统计课消收入、消课 / 请假 / 购课节数，并按学生拆分。
- **登录与同步**：本版本为前端演示，登录与跨设备同步为本地模拟（数据存在浏览器 localStorage）。

## 本地运行

无需任何依赖，直接双击 `index.html` 用浏览器打开即可。也可以用任意静态服务器托管本目录。

> 数据保存在浏览器本地（localStorage），刷新不丢；换浏览器或清除浏览器数据会丢失。

## 部署到 GitHub Pages

1. 把本目录推送到 GitHub 仓库。
2. 仓库 **Settings → Pages** 里，Source 选择 `Deploy from a branch`，分支选 `main`、目录选 `/ (root)`。
3. 保存后稍等，即可通过 `https://<用户名>.github.io/<仓库名>/` 访问。
